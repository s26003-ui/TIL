기술

HTML / CSS

웹 페이지의 표준 구조를 설계하고 스타일을 입히는 핵심 기술입니다. 시멘틱 태그를 활용해 웹 표준을 준수하는 마크업이 가능하며, 다양한 디바이스에 대응하는 반응형 레이아웃을 구현할 수 있습니다. CSS3의 애니메이션, 트랜지션, flexbox 등을 활용해 동적이고 세련된 디자인을 구현할 수 있습니다.

JavaScript

웹 페이지에 동적 기능을 추가하는 데 사용되는 프로그래밍 언어입니다. DOM 조작, 이벤트 처리, 비동기 프로그래밍 등을 통해 사용자와의 상호작용을 향상시킬 수 있습니다. 바닐라 자바스크립트로 Todo 애플리케이션과 랜덤 고양이 이미지 사이트를 직접 구현한 경험이 있습니다.

Python

웹 개발과 데이터 분석에 사용되는 인기 있는 프로그래밍 언어입니다. Flask와 Django와 같은 웹 프레임워크를 사용하여 빠르게 웹 애플리케이션을 개발할 수 있습니다. 간결한 문법으로 빠르게 배울 수 있어 입문 언어로도 많이 활용됩니다.
